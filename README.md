# ArraysEasy.java – DSA Array Problems in Java

This repository contains a Java class `ArraysEasy` that demonstrates solutions to commonly asked array problems in Data Structures & Algorithms (DSA). The problems range from basic array operations to more optimized approaches using two pointers and hashing.

## 🔧 Features & Problems Solved

- ✅ Find the largest and second largest elements (with and without sorting)
- ✅ Check if the array is sorted
- ✅ Left and right rotate an array by 1 position
- ✅ Left rotate by `d` positions (brute-force)
- ✅ Move all zeroes to the end (brute-force & optimal)
- ✅ Linear search
- ✅ Union and intersection of two arrays (HashSet & two-pointer approach)
- ✅ Find missing number (using sum and XOR methods)
- ✅ Find maximum consecutive 1s
- ✅ Find the element that appears only once (others appear twice)
